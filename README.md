# ⏰ time-aware-context

> 时间感知上下文校准 Skill — 当对话涉及日期/日程/时间计算时，自动获取服务器时间并注入上下文，避免时间误差导致的错误。

## ✨ 解决什么问题

LLM 训练数据有截止日期，跨时区对话容易算错时间。本 Skill 在每轮对话开头自动校准：

```
【当前系统时间校准】
- 服务器时间：2026-07-29 11:52:03 CST (Wednesday)
- 时区：Asia/Shanghai (UTC+8)
- NTP 同步状态：active
```

## 🎯 触发场景

- ✅ "今天/明天/昨天几点"、"7/30 训练"、"X 天后"
- ✅ "还有几天"、"还剩多少时间"、"倒计时"
- ✅ "时区转换"、"美东几点"、"UTC 时间"
- ✅ 训练计划、日程安排、会议提醒、待办
- ❌ "你好"、"谢谢"（无时间概念不触发）

## 🚀 工作流

1. **关键词检测** — 扫描用户消息，匹配时间相关概念
2. **时间获取** — 执行 `date "+%Y-%m-%d %H:%M:%S %Z (%A)"`
3. **上下文注入** — 在回答最前面插入校准块
4. **基于校准时间回答** — 所有相对时间以服务器时间为准

## 📁 文件

- `SKILL.md` — Skill 完整定义（YAML frontmatter + 触发条件 + 工作流 + 示例）

## ⚙️ 关键规则

- **冲突以服务器为准**：用户说"今天 7/30"但系统是 7/29，应答"明天 7/30"
- **时区敏感**：跨时区对话需主动计算时差
- **不要过度触发**：普通聊天不触发
- **缓存复用**：单次对话多次触发复用第一次时间
